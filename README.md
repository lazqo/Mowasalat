# Mowasalat · مواصلات

A privacy-first, Arabic-first public transport app for countries where buses have no published schedule. Drivers pick a route; passengers pick a destination; each sees the other on a map. No payments, no names.

- First country: Jordan (pilot in Irbid). Next: Syria.
- Two apps: **Passenger** and **Driver**, plus an internal ops admin.
